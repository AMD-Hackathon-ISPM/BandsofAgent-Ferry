# GitHub Integration

This directory contains GitHub API integration.

## Files to Implement

- `client.go` - GitHub API client
- `service.go` - GitHub service with business logic
- `types.go` - GitHub-related types

## Responsibilities

- GitHub authentication (PAT)
- Repository operations (clone, read)
- Branch creation and management
- File commit operations
- Pull request creation
- Review comment posting
- PR metadata storage
